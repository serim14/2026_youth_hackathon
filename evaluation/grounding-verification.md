# 원문 제한 경로 검증

모델이 자유 문장을 생성하던 경로를 원문 항목 ID 선택으로 바꾸고, 코드가 원본 필드를 인용해 답변하도록 수정한 뒤 검증했다. 새로운 숫자·계산식·조건을 담은 모델 문장은 출력하지 않는다. 누락 정보, 관련 공고 없음, 개인 신청 내역 및 현재 접수 여부에는 정해진 안내 문구를 사용한다.

- 자동 테스트: 51개 통과
- 실제 API 회귀 검증: 15개 중 15개 통과
- 답변 모델: `.env`의 `gpt-4o-mini`
- 원본 필드 경로와 인용 문자열을 저장된 정책 레코드와 대조
- 기존 30문항 평가 3개 세트와 수정 과정의 중간 결과 보존

초기 실제 검증은 12/15였다. 복합 질문에서 금액이 빠지는 문제, 다른 가족돌봄 사업의 기간을 선택하는 문제, 일부 정보가 있는 질문을 전부 답변 불가로 처리하는 문제를 수정하고 같은 15개 사례를 다시 실행했다. 초기 결과는 [grounding-verification-attempt1.json](grounding-verification-attempt1.json), 최종 응답·원문 근거·상태는 [grounding-verification.json](grounding-verification.json)에 보존했다.

이 검증은 기존 오류를 대상으로 한 회귀 검증이며 미사용 질문에 대한 정답률 평가는 아니다. 원문 자체의 오류·최신성 및 모델의 관련 근거 선택 오류까지 제거한 것으로 해석하면 안 된다. 답변 형식은 요약문 대신 원문 인용 중심이다.

세 번째 실험의 실패를 반영한 최종 코드에서도 15/15를 확인했다. 최종 코드 해시는 grounding-verification.json의 codeHashes에 있으며 round3_release/results.json의 코드 해시와 같다. 동일 30문항 전체 결과는 [개선 전후 비교](round3_release/comparison.md)와 [추가 검토](round3_release/review.md)에 있다. 30문항에서는 근거 선택 불일치로 차단된 T15가 남았으므로 이 15개 회귀 성공을 전체 답변 성공으로 해석하지 않는다.
